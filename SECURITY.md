# Security Policy

Please do not include secrets, SQL connection strings, OAuth credentials, payment keys, or personal customer information in public issues.

For a vulnerability report, use GitHub's private vulnerability reporting feature if enabled, or contact the repository owner privately.

Values in the committed application settings have been replaced with empty placeholders. If any previous value was a real credential, rotate it at its issuing service. Removing values from the latest version does not remove them from Git history.
